# Port check of the retired range runtime (R5-120)

Full table for section 5 of the [distributed transactions release notes](R5.md).
It covers every test in `giggles-distributed`, `giggles-placement`,
`giggles-range-history` and `giggles-membership`, checked against main at
0bbdce3d (GD-0075 Phase 13).

- `ported`: an R5 test was written as this test's port. It names the legacy test,
  or the plan made it the acceptance test.
- `replaced`: R5 tests guard the same property.
- `dropped`: the property belongs only to the legacy runtime. Where an R5 test
  covers a related property, it is shown in brackets.
