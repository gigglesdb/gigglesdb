# Security

Report vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/gigglesdb/gigglesdb/security/advisories/new)
on github.com/gigglesdb/gigglesdb: **Security** tab, then **Report a vulnerability**.
Do not open public issues for vulnerabilities.

Include the affected version or commit, configuration and platform, reproduction
steps or a minimal proof of concept, expected and observed behavior, and the
potential impact. Omit secrets and private user data.

While GigglesDB is pre-1.0, supported versions are the latest main and latest
release. We aim to acknowledge reports promptly.

See the [server security model](crates/giggles-server/SECURITY.md) for the
server's trust boundaries and security assumptions.
