# Boulder Brand Kit

Products: GigglesDB, Skedaddle, Nunya

## Primary files
- gigglesdb-boulder.svg   — holding the data cube
- skedaddle-boulder.svg   — carrying the cube on the move
- nunya-boulder.svg       — wary and watchful, protecting the cube with both arms
- boulder-family.svg     — all three logos together

Each product also has a -transparent.svg logo and an -icon.svg mascot.
The primary logos retain the yellow presentation background; delete or recolor
the group/element named background to change it. Transparent variants omit it.

These are genuine vector files: path geometry, no embedded bitmap images,
no external resources, no font dependency. The selected generated lettering
has been converted to outlines; this package does not include an installable
font. Editable groups: mascot, stone-body, face-and-data-cube, wordmark.

## Palette
- Ink: #151515
- Ivory: #FFF3C4
- Yellow: #FFFF00

The outlines are cleaned vector traces of the approved generated designs.
Small edge differences from the raster concepts are intentional cleanup.
Use mascot-only files for avatars. Tiny favicons may benefit from a separate
simplified face mark, especially below 32 px.

Brand review: a targeted database-brand search did not identify a close match
for this boulder character. Rock/golem characters exist in other fields; this
is not an exhaustive similarity or trademark clearance.

Nunya facial features are in the editable wary-expression group.
